# Hospital Analytics Dashboard (Power BI)

## Problem Statement
Hospitals require data-driven insights to monitor patient flow,
bed occupancy, and treatment outcomes.

## Solution
This project presents an interactive Power BI dashboard that analyzes
hospital KPIs such as admissions, bed occupancy rate, ALOS, and outcomes.

## Dataset
Hospital operational dataset containing admissions, departments,
bed usage, and patient outcomes.

## Tools Used
- Power BI Desktop
- Excel / CSV

## Features
- KPI cards
- Filters and slicers
- Department-wise analysis
